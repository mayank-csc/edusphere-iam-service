🔐 IAM Service (Identity & Access Management)

Creates and manages user accounts for tenant admins. Exclusively Kafka-driven — no public REST API.

Port: 8091 MySQL: edusphere_iam_db BCrypt Password Hashing Spring Boot 3.3.4
Overview

The IAM Service (Identity & Access Management) is responsible for creating and managing user accounts for tenant admins on the EduSphere platform. It operates exclusively through Kafka events — there is no public REST API.

Key responsibilities:

  • Listen for USER_CREATION_REQUESTED events and create tenant admin accounts
  • Hash all passwords with BCrypt before persisting to the database
  • Validate email uniqueness before creating a user
  • Soft-delete users (set active = false) as a compensating transaction when saga fails
  • Stores user records in MySQL database edusphere_iam_db (port 8091)
Service Flow
flowchart TD KIN[Kafka: USER_CREATION_REQUESTED] --> CHK{Email already\nexists in DB?} CHK -->|Yes| FAIL[Publish USER_CREATION_FAILED\nreason: email exists] CHK -->|No| HASH[Hash password with BCrypt] HASH --> SAVE[Save User to DB\nrole=TENANT_ADMIN, active=true] SAVE --> PUB[Publish USER_CREATED\nwith userId + tenantId] KIN2[Kafka: USER_DELETION_REQUESTED] --> FIND[Find user by sagaId] FIND --> DEACT[Set active = false] DEACT --> PUB2[Publish USER_DELETED]
Kafka Events
ℹ️ All user lifecycle operations are event-driven. Passwords are never stored in plain text — BCrypt hashing is applied before saving.
